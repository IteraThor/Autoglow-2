Extension Setup
Use Chrome on this computer: AutoGlow only accepts the extension from the machine it runs on. Linux: setup.sh installs the extension automatically (restart Chrome once). Otherwise:
  1. In Chrome, open chrome://extensions and switch on Developer mode.
  2. Click Load unpacked and select this folder:
    chrome_extension
  3. Open play.autodarts.com and play as usual. The toolbar icon shows ON while AutoGlow receives the game.
